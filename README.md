# freertos-multiheap-manager

ESP32-S3 기반 정책형 멀티힙 메모리 매니저 + 온디바이스 실시간 모니터링 대시보드

## 개발 목적

ESP32-S3는 빠르지만 작은 내부 SRAM(512KB, Wi-Fi 구동 시 가용량은 그보다 크게 감소)과,
크지만 느리고 DMA 제약이 있는 외부 PSRAM(8MB)을 함께 사용한다. 두 메모리는 대체
관계가 아니라 용도가 다른 자원이며, 어떤 버퍼를 어디에 둘 것인가가 성능과 안정성을
결정한다.

그러나 실무에서는 이 판단이 할당 지점마다 개발자의 손에 맡겨져, ① 메모리 배치 정책이
코드 전반에 흩어져 파악이 어렵고 ② 할당 실패 시 원인이 절대량 부족인지 단편화인지
판단할 근거가 남지 않는다.

이 프로젝트는 할당 의도(크기·DMA 필요 여부·수명)를 입력받아 힙 리전을 결정하는 정책
엔진으로 배치 규칙을 단일 지점에 명시하고, 단편화 추이와 태스크 스택 사용량을 보드
LCD에 실시간 시각화해 평소 드러나지 않는 메모리 상태를 관측 가능하게 만들었다. 검증
부하로는 Wi-Fi TLS 통신과 이미지 수신을 사용해, 반복 연결로 단편화가 자연 누적되는
실제 IoT 필드 장애와 동일한 조건에서 정책을 시험했다.

목표는 총 메모리 사용량 감소가 아니라, 희소 자원인 내부 SRAM의 여유 확보와 근거 있는
수치 기반 메모리 관리다.
