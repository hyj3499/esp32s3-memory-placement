# esp32s3-memory-placement

**탐구 목표:** 내부 SRAM과 외부 PSRAM의 특성을 이해하고, 실제 메모리 사용량을 근거로 버퍼 배치와 태스크 스택 크기를 설계하는 것을 목표로 함. 전체 여유 메모리뿐 아니라 최대 연속 할당 공간과 부하 중 최소 여유량을 함께 측정해, 메모리 부족의 원인을 구체적으로 분석

**개발 목적:** ESP32-S3에서 Wi-Fi·HTTPS 통신과 LCD 출력을 함께 실행하여 큰 스트레스를 줄 때 발생하는 내부 SRAM 부담을 줄이고자 개발함. 이때 외부 PSRAM에 공간이 남아 있어도 내부 SRAM의 연속 공간이 부족하면 큰 버퍼를 할당하기 어렵다. 이를 해결하기 위해 **메모리 계측 → mbedTLS 배치 변경 → 스택 크기 조정 → 용도 기반 할당 래퍼 적용** 순서로 최적화를 진행하고, 결과를 LCD 대시보드에서 확인할 수 있도록 구현함.
